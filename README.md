A set of my fav global keybinds. cuz i hate having to relearn the keys in other games

# The binds we dont change

<kbd>W</kbd> + <kbd>A</kbd> + <kbd>S</kbd> + <kbd>D</kbd> are movement obv 

# the binds themselfves
